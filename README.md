# Daily English

Daily English is an early MVP for a focused English-learning routine. The first screen combines four daily blocks: vocabulary, speaking, diary writing, and a quick review.

## Implemented

- Responsive daily dashboard.
- Interactive lesson selection and completion progress.
- CEFR progress preview and weekly activity cards.
- Light and dark themes saved on the current device.

The data shown on the dashboard is demo data. Authentication, Supabase persistence, AI feedback, audio recording, and real spaced-repetition logic are not implemented yet.

## Local development

The project uses the npm lockfile in this repository.

```bash
npm install
npm run dev
```

Available checks:

```bash
npm run build
npm run lint
```
