# Local practice corpora

Place downloaded corpus archives and extracted files here. Everything in this
directory except this README is ignored by Git.

The application never reads this directory at runtime. Before importing a real
release, create a pinned manifest with its release identifier, download date,
SHA-256 checksum, license, terms URL, and importer version.

Do not place the general Tatoeba CC BY export here for Package 1. Only the
separate `Sentences (CC0)` export is allowed.
